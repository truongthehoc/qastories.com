# Git Commit Rule

- Sau mỗi lần cập nhật code, sửa lỗi, thêm tính năng hoặc build thành công, hãy LUÔN LUÔN tự động chạy `git add .` và tạo commit lên git với commit message rõ ràng theo chuẩn conventional commit (vd: `fix(...)`, `feat(...)`).
- Không cần đợi người dùng phải nhắc commit.
